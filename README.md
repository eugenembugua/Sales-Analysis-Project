# BMW Global Sales Analysis & Forecasting (2010–2024)

## 📌 Project Overview
This project analyzes a decade of BMW's global sales data to identify market trends, consumer preferences, and pricing strategies. The goal is to prepare a clean dataset for **Forecasting** and **Customer Segmentation**, enabling data-driven marketing actions based on regional performance and vehicle configurations.

## Visual Analysis & Insights

### 1. Sales Performance & Growth Trends
* **Annual Revenue:** The project tracks "BMW Annual Sales (USD)" showing fluctuations between $240M and $260M.
* **Growth Metrics:** Identified a **Peak Growth of 6.22%** and a **Lowest Growth of -7.17%**, which are critical markers for forecasting volatility.
* **Sales Classification:** Segmented models into "High" and "Low" sales categories to focus analysis on top-performing assets.

### 2. Regional Market Competitiveness
* **Market Share:** A deep dive into regional distributions (Africa, Asia, Europe, Middle East, North America, South America) shows balanced global competitiveness.
* **Consumer Favorites:** Identified "Fan Favourite Models" per region, such as the **i3** and **X3** in Africa versus the **7 Series** and **i8** in other markets.

### 3. Configuration & Price Sensitivity
* **Transmission & Fuel:** Analyzed the interplay between **Automatic vs. Manual** transmissions across **Diesel, Electric, Hybrid, and Petrol** engines.
* **Pricing Strategy:** Facet charts track "Average Price Trends" (2011–2024) for every model (3 Series, 5 Series, X5, M3, etc.), revealing how price shifts impact sales volume.

## 🛠️ Tech Stack & Requirements
The project is built using a modern Python data science stack. The libraries in requirements.txt are required to run the analysis and render the interactive Plotly charts.
